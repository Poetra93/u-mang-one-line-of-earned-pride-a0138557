# One Line of Earned Pride

One line, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene. Free to enter, judged in pairs on genuine earned pride, a concrete scene, landing in one read and freshness.

This program writes a single fixed line of text to `/output/entry.txt`: a boy who has fallen off his bike forty times finally rides past his house without wobbling, and his father, watering the roses, forgets the hose is running.

## Run

```sh
node main.ts
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Node 22 or later, standard library only, no network, no randomness — the output is byte-identical on every run.
